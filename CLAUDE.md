# ProgressOr (pm-tracker)

React + TypeScript + Vite app for tracking developer work against Jira / GitHub / GitLab.
Production: **https://www.progressor.work** (Vercel project `progressor`).
Backend is a **separate repo**: `ChobanyanNarek/progressor-backend` (NestJS on Render,
reached at `VITE_API_URL`).

## Commands

| | |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run gate` | the full pre-push gate — run it before every push |
| `npm test` | vitest |
| `npm run build` | `tsc && vite build` |

The gate is: `typecheck` → `typecheck:sync-core` → `check:sync-core` → `test` → `build`.

## Layout

- `src/` — the app. `src/store/` holds state; `src/sync-core/` is the pure sync logic.
- `src/sync-core/` is **vendored into the backend**. Edit it here, then run
  `node scripts/vendor-sync-core.mjs` and commit both repos. `check:sync-core` fails on a stale copy.
- `api/`, `scripts/`, `jira-extension/`, `types/`.

## Local setup

`.env` is gitignored and holds one variable:

```
VITE_API_URL=https://progressor-backend.onrender.com
```

`.env.production.local` is generated by `vercel env pull` — do not create it by hand and
never commit it.

## Notes

The app is a PWA with a network-first service worker: after a deploy, users must hard-refresh
(Cmd+Shift+R) to pick up new code.
